# Price data

## What is in this folder

| File | What it is |
| --- | --- |
| `staples.csv` | Our hand-picked list of 86 student staples. For each ingredient: English and Spanish name, the Mercadona product (SKU) we chose for it, a diet tag and allergen tags. Written by us. |
| `prices_mercadona_mad1_2026-09-21.csv` | The price snapshot the app uses. Generated by `scripts/build_price_snapshot.py`. Do not edit by hand. |
| `raw/` | Downloaded source files. Ignored by Git. |

## Where the prices come from

Prices are **real Mercadona online prices for the Madrid zone (`mad1`), captured on 2026-09-21**.

Source: [OpenCesta](https://github.com/ruvelro/opencesta), an open dataset of Spanish supermarket prices, release `prices-2026-09-21`. The dataset is published under the [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/) licence. Our snapshot is a filtered extract of it and is shared under the same licence.

We use a fixed snapshot on purpose. Mercadona has no official public API, and scraping its website would be fragile and against the spirit of its terms. A dated snapshot keeps the app reproducible: the same inputs give the same shopping total.

## Limitations (read before trusting a number)

- Prices are frozen on 2026-09-21. They will drift from shelf prices over time.
- Madrid zone only. Other cities can differ.
- One product per ingredient, usually the cheapest store-brand option. The app cannot compare brands.
- Loose fruit and vegetables are priced per average piece (for example one potato = 0.26 kg), as the online shop does.
- **Allergen and diet tags were written by us from general knowledge, not read from product labels.** They are indicative only. Always check the real label.

## How to rebuild the snapshot

```
pip install -r scripts/requirements.txt
mkdir -p data/raw
curl -L -o data/raw/prices.tar.gz https://github.com/ruvelro/opencesta/releases/download/prices-2026-09-21/prices.tar.gz
tar -xzf data/raw/prices.tar.gz -C data/raw
python3 scripts/build_price_snapshot.py "data/raw/data/chain=mercadona/zone=mad1/date=2026-09-21/prices.parquet"
```

The script stops with an error if any SKU from `staples.csv` is missing from the price file.
